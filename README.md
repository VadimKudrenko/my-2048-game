# 🎮 2048 Game – Vanilla JavaScript Edition

**2048 Game** – a practical implementation of the classic puzzle game built entirely with Vanilla JavaScript. This project was created to deepen knowledge of JavaScript fundamentals and DOM manipulation without relying on animations or external libraries. The focus is on clean logic and solid structure.

## 🔗 Live Preview
[Play the game here](https://vadimkudrenko.github.io/my-2048-game/)


## 🛠️ Technologies Used

### Core
- **HTML5** – Markup structure
- **SCSS** – Styling and layout control
- **JavaScript (ES6+)** – Game logic and DOM interaction

### Development & Deployment
- **ESLint** – Code quality and linting

## ✨ Features
- **Classic 2048 Mechanics**: All standard features of the original game (merge, move, score counting, win/loss conditions)
- **Fully Functional Grid System**: Dynamic rendering of the 4×4 board
- **Keyboard Controls**: Intuitive arrow-key navigation
- **Practical Focus**: Built without animations to maintain a clear focus on logic and DOM operations

## 🚀 Getting Started

Follow these instructions to run the project locally:

### 1. Clone the repository
```bash
git clone https://github.com/VadimKudrenko/museum-namu-landing.git

cd museum-namu-landing

# Using VSCode with Live Server:
code .
# Then click "Go Live"

# Or open manually:
open index.html
# (or double-click the file in your file explorer)
```

### 2.Install dependencies:
```bash
npm install
# or
yarn install
```

### 3.Run the project locally:
```bash
npm start
# or
yarn start
```
